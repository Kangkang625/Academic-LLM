# 方法与数据

本说明整理自《学术知识图谱驱动的大模型训练与测评报告》。其中方法设计不等同于所有环节均已开源或可复现。

## 论文解析与知识图谱

报告描述使用 MinerU 对 PDF 进行版面解析和多模态预处理，保留章节、段落、表格、公式和来源位置。按照研究任务建立实体、关系和约束，从文本、表格、公式及相关图文上下文抽取知识，并通过证据绑定、语义对齐、冲突检测和一致性验证组织知识图谱。

## 训练数据

报告描述从候选问题和答案的锚点出发检索局部子图，识别支持答案的路径与相关但不足以推出答案的困难干扰。教师模型生成答案、推理和证据映射；经检查后，将图谱监督映射回文本证据。样本包含论文上下文、问题、文本推理、答案、证据位置和难度标签。方法设计包含由易到难的课程安排。

报告采用约数：约 1 万篇论文、约 2—3 万条训练数据。准确数量、学科分布、来源、教师模型、生成及审核细节和各类样本占比均待补充。论文文本、衍生问答和图谱的开放范围与许可尚待核实。

## 训练

底座为 `Qwen3.8-27B`，训练使用 4 × NVIDIA H100，LoRA rank 8。
