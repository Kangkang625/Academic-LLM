## 模型用途

模型旨在支持基于论文文本的学术问答，例如理解论文中的方法、实验设置和研究结论，以及组合论文上下文中的多个证据回答问题。实际适用学科、语言及能力范围需要通过测试进一步确认。

知识图谱主要参与训练数据构建。模型本身不等同于实时文献检索系统，也不能保证回答中的事实和引用准确；使用者应对照原始论文核查。

## 数据与训练

根据现有报告，项目以约 **1 万篇论文**为知识来源，构建约 **2—3 万条训练数据**，在 **4 张 NVIDIA H100** 上开展训练。这些规模为近似统计。

报告描述的流程包括论文解析、证据与知识抽取、图谱中支持路径和困难干扰的构造，以及通过教师监督和证据映射将图谱监督转换为文本问答。训练样本包括论文上下文、问题、文本推理、答案、证据位置和难度标签。

## 快速开始

以下为 Transformers 调用示例，需替换模型 ID，并根据最终权重确认依赖版本、硬件要求、聊天模板及生成参数。示例尚未使用实际发布的合并权重验证，且不代表报告中的评测配置。

```bash
pip install torch transformers accelerate
```

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "YOUR_ORG/YOUR_MODEL"  # 替换为实际 Hugging Face 模型 ID
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, torch_dtype="auto", device_map="auto"
)

paper_text = "在此粘贴论文内容。"
question = "论文的主要贡献是什么？"
messages = [{"role": "user", "content": f"论文内容：\n{paper_text}\n\n问题：{question}"}]
prompt = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True
)
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
with torch.inference_mode():
    outputs = model.generate(**inputs, max_new_tokens=512, do_sample=False)
print(tokenizer.decode(outputs[0][inputs.input_ids.shape[-1]:], skip_special_tokens=True))
```

## 局限性

- 模型可能生成与论文不符的事实、数字或引用；请核对原文。
- 目前公开的报告不足以判断其在未见论文、不同学科或不同语言上的泛化表现。
- 长论文可能超过模型实际可用上下文；截断可能导致关键证据缺失。具体上下文长度和处理方式待验证。
